## <b>ADR 005:</b> Modelo de Comunicação Híbrido (Síncrono e Assíncrono)

<b>Contexto:</b> A plataforma EduVerse possui funcionalidades com diferentes requisitos de tempo de resposta. Operações como autenticação, consulta de cursos e acompanhamento de progresso exigem retorno imediato ao usuário. porém, processos relacionados à recomendações por IA, coleta de eventos de uso e análise de grandes volumes de dados podem demandar maior tempo de processamento. Além disso, o requisito funcional RF03 determina a existência de uma fila de espera para lidar com grandes volumes de solicitações ao serviço de IA.

<b>Status:</b> Proposto

<b>Decisão:</b> Foi decidido adotar um modelo híbrido de comunicação, combinando as abordagens síncronas e assíncronas. A comunicação síncrona será utilizada para operações que exigem resposta imediata ao usuário, por meio de APIs REST. Já a comunicação assíncrona será utilizada para processamento de recomendações, envio de dados para análise pela IA, e outras operações intensivas, utilizando filas de mensagens para desacoplar componentes e absorver picos de demanda. 

<b>Consequências (Trade-offs):</b>

<b>Ganhos:</b>

- Melhor <b>escalabilidade</b> diante de picos de utilização.

- Menor <b>tempo de resposta</b> da aplicação.

- Redução do <b>acoplamento</b> entre componentes do sistema.

- Maior tolerância a falhas temporárias de sistemas externos.

<b>Perdas:</b>

- Maior <b>complexidade de implementação</b> e monitoramento.

- Necessidade de rastreamento e gerenciamento das mensagens em fila.

- Possibilidade de <b>consistência eventual</b> em determinadas operações.

<b>Alternativas Consideradas:</b> Foi considerada a adoção exclusiva de comunicação síncrona, porém essa abordagem aumentaria a dependência da disponibilidade da API de IA e aumentaria os tempos de resposta para operações complexas. Também foi considerada uma arquitetura totalmente assíncrona, mas isso adicionaria complexidade para funcionalidades simples que exigem retorno imediato ao usuário, como autenticação e consultas rápidas. Dessa forma, o modelo híbrido foi considerado a alternativa mais equilibrada para o EduVerse.
